Surgical Procedure Sets

20 ready-assembled instrument sets covering 1,259 instrument places, from a 13-piece suture set to a 112-instrument major surgery tray. Each set is assembled from the Opix catalog, kitted in a perforated sterilization container with silicone mat and contents card, and quoted as a single unit.

Every list below is a starting point. Lines can be added, removed or exchanged for another pattern from the same catalog section, and all sets are available in tungsten-carbide, economy and private-label configurations.
